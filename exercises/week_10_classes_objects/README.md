# 📖 Week 10: Classes and Objects
**Think Python**: Chapter 15

In this module, you will practice defining user-defined types (classes), instantiating objects, accessing attributes, and implementing geometric operations on `Point` and `Rectangle`.

---

## 🎯 Exercises

1. `Point(x, y)`:
   - A class representing a point in 2D space.

2. `distance_between_points(p1, p2)`:
   - Computes Euclidean distance $\sqrt{(p2.x - p1.x)^2 + (p2.y - p1.y)^2}$.

3. `Rectangle(corner, width, height)` & `find_center(rect)`:
   - Computes the center `Point` of a rectangle.
