# 📖 Week 02: Variables, Expressions and Statements
**Think Python**: Chapter 2

In this module, you will practice type conversion, string repetition/concatenation, bookstore wholesale pricing, and time arithmetic calculations.

---

## 🎯 Exercises

1. `calculate_bookstore_cost(num_books)`:
   - Cover price: $24.95.
   - 40% discount for bookstores.
   - Shipping: $3.00 for the first copy and $0.75 for each additional copy.
   - Return total wholesale cost rounded to 2 decimal places.

2. `calculate_arrival_time(start_hour, start_min, easy_pace_miles, tempo_pace_miles)`:
   - Easy pace: 8 min 15 sec per mile.
   - Tempo pace: 7 min 12 sec per mile.
   - Return tuple `(arrival_hour, arrival_min)`.

3. `format_user_banner(text, width, border_char)`:
   - Returns a centered string surrounded by `border_char`.
