## 🎯 Exercises

Open [`practice.py`](practice.py) and complete the three exercises:

### 1. Wholesale Bookstore Cost (*Think Python 2.2, Question 2*)
- Cover price of a book: $24.95.
- Bookstores get a 40% discount ($0.60 \times 24.95$).
- Shipping: $3.00 for the first copy, and $0.75 for each additional copy.
- Calculate the total cost for 60 copies and print your result with `print("Bookstore cost:", total_cost)`.

### 2. Running Pace & Breakfast Arrival Time (*Think Python 2.2, Question 3*)
- Start time: 6:52 AM.
- Easy pace: 8 minutes 15 seconds per mile (run for 2 miles total = 1 mile out, 1 mile back).
- Tempo pace: 7 minutes 12 seconds per mile (run for 3 miles).
- Calculate arrival hour and minute, and print the arrival time in `HH:MM` format (e.g. `07:30`).

### 3. User Display Banner
- Create a banner with the title `"PYTHON CSE 101"` centered in a 30-character line surrounded by `=` characters.
- Print your banner with `print("Banner:", banner)`.
