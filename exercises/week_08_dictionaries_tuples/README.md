# 📖 Week 08: Dictionaries and Tuples
**Think Python**: Chapters 11 & 12

In this module, you will practice dictionary frequency counting, invert dictionary mapping, and tuple packing/unpacking.

---

## 🎯 Exercises

1. `word_frequency(text)`:
   - Takes a string and returns a dictionary mapping each lowercased word to its count.

2. `invert_dictionary(d)`:
   - Inverts a dictionary so that each value becomes a key pointing to a list of original keys.

3. `most_frequent_letters(text, top_n=3)`:
   - Returns the `top_n` most frequent alphabetic characters as a list of tuples `[(char, count), ...]`.
