# 📖 Week 06: Strings and Lists
**Think Python**: Chapters 8 & 10

In this module, you will practice string indexing, slicing, palindrome checks, list cumulative sums, and duplicate removal.

---

## 🎯 Exercises

1. `is_palindrome(word)`:
   - Returns `True` if `word` is a palindrome (ignoring spaces and case), else `False`.

2. `cumulative_sum(numbers)`:
   - Takes a list of numbers and returns the cumulative sum list where the $i$-th element is the sum of the first $i+1$ elements.
   - Example: `[1, 2, 3]` $\to$ `[1, 3, 6]`.

3. `remove_duplicates(elements)`:
   - Returns a new list containing elements with duplicates removed, preserving the original order of appearance.
