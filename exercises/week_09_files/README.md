# 📖 Week 09: Files and Exceptions
**Think Python**: Chapter 14

In this module, you will practice file reading, writing, line counting, word search, and safe file parsing with `try...except`.

---

## 🎯 Exercises

1. `count_lines_and_words(filepath)`:
   - Returns a tuple `(line_count, word_count)`.

2. `find_lines_with_keyword(filepath, keyword)`:
   - Returns a list of strings containing all lines in the file matching `keyword` (case-insensitive).

3. `safe_read_number_file(filepath)`:
   - Reads a file containing one number per line. Returns the sum of all valid numbers, skipping invalid lines gracefully.
