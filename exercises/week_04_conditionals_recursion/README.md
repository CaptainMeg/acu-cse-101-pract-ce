In this module, you will practice boolean expressions, nested/chained conditionals, base cases in recursion, and recursive sequence generators.

## 🎯 Exercises

1. `is_triangle(a, b, c)`:
   - Triangle inequality theorem: If any of the three lengths is greater than the sum of the other two, you cannot form a triangle. Otherwise, you can.
   - Returns `True` or `False`.

2. `factorial_recursive(n)`:
   - Computes $n!$ using recursion.

3. `fibonacci_recursive(n)`:
   - Computes the $n$-th Fibonacci number ($F_0 = 0, F_1 = 1, F_n = F_{n-1} + F_{n-2}$).
