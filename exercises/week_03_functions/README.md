# 📖 Week 03: Functions
**Think Python**: Chapter 3

In this module, you will practice function composition, arguments vs parameters, return values, and grid drawing.

---

## 🎯 Exercises

1. `right_justify(s, width=70)`:
   - Returns string `s` padded with leading spaces so that the last letter is in column `width`.

2. `do_twice(func, val)`:
   - Takes a function object `func` and argument `val`, calls `func(val)` twice, and returns the result of the second call.

3. `hypotenuse(a, b)`:
   - Computes the length of the hypotenuse of a right triangle: $\sqrt{a^2 + b^2}$.
