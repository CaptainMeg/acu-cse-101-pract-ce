# 📖 Week 11: Classes and Functions
**Think Python**: Chapter 16

In this module, you will practice pure functions vs. modifiers using a custom `Time` class.

---

## 🎯 Exercises

1. `Time(hour, minute, second)` class.
2. `time_to_int(time)` & `int_to_time(seconds)`:
   - Convert a Time object to total elapsed seconds since midnight and vice versa.
3. `add_time(t1, t2)`:
   - Pure function that adds two `Time` objects and returns a new `Time` object.
4. `increment_time(time, seconds)`:
   - Modifier function that modifies an existing `Time` object in-place.
